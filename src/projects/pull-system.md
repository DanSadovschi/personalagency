Pull System needed a single page that made a statement. No navigation, no content hierarchy, no secondary objectives — one screen that had to stop the scroll immediately and leave an impression. The challenge with a one-page brief is that there's nowhere to hide: the design either works or it doesn't.

## What we built

We built everything from scratch: the animation concept, the visual identity, the colour system, and the complete production build. The animation was the starting point rather than an afterthought — the whole design was built around making it feel inevitable. Original motion, not a library effect dropped into an existing layout.

The colour choices are deliberate and bold. The combination of the animation and the palette creates a specific feeling: kinetic, high-energy, and visually distinct from anything in the same space. There's nothing generic about it because nothing was taken off the shelf.

Custom JavaScript handles the animation engine. The site performs well on mobile, where the effect was rebuilt rather than simply scaled down.

## The results

Pull System launched and gained traction quickly within the design and tech community — the page was being shared as an example of what a single-page site could look like when the constraints were treated as an advantage rather than a limitation. It became a reference point for what high-quality one-page design looks like.
